# 项目共享代码 Review 与交付边界

日期：2026-09-23；2026-09-29 更新。范围：本地未提交的项目共享改造。结论：P0–P6 的代码链路已接通，P7 的真实跨账户、多机验收尚未完成。项目共享的环境与构建开关已移除，Mac 和 iPhone 入口默认显示；线上服务已部署，端到端可用性仍须单独验证。

## 本轮发现并修复

1. 命令领取、续租和完成原先先读取权限、再更新状态，成员撤权可能插入两者之间。Account API 现在把成员、设备、权限版本和密钥版本检查放进条件更新；撤权后不能续租，也不能把已失效命令确认完成或登记草稿 Chat。
2. 成员的新 Chat 草稿原先只存在当前页面，重启后找不回。现在服务端只返回本人未发布草稿和进行中消息的命令，Mac 从本账户项目密钥恢复标题与请求状态；旧密钥不可用时仍显示可访问的草稿 ID 和通用标题。
3. 成员界面原先等待命令最多 90 秒，长 Agent 任务会被误报超时。现在提交后保留请求 ID，独立轮询状态，重新打开页面可恢复进行中的请求和停止操作。
4. 切换默认执行 Mac 后，原执行机无法再授权新执行机，形成密钥交付死锁。现在任一已登记、持有当前密钥的所有者 Mac 可完成设备授权；密钥生成权固定到该 epoch 的指定 Mac，切换执行机不会导致双重生成。撤权轮换时把下一 epoch 的生成权交给当前执行 Mac。
5. 归档 Chat 被普通 `listRuns()` 过滤，导致历史共享不完整，也无法发布归档状态。共享发布改用包含归档记录的列表，成员可读归档历史，归档后不能继续发送。
6. 900px 窗口中共享页继承普通内容页底部留白，输入框落到视窗外。共享页改用完整高度的对话布局；开发 Web 预览已在 Light/Dark 检查多人署名、侧栏和输入框。
7. 主机在最后一次心跳后断线时，刚接收的命令可能滞留并在恢复上线后自动运行。尚未领取的命令现在 60 秒后标为中断，成员须检查状态后重新提交；执行机心跳只在项目目录、密钥和当前快照均可用时发送。
8. 新成员原先必须先完成本机 Agent 和项目目录引导才能进入“与我共享”。账户引导现在提供邀请令牌入口，接受成功后直接进入共享项目；默认关闭共享时侧栏不显示该入口。
9. Account API 的已授权设备请求原先不返回封装后的项目密钥，导致 Mac/iPhone 客户端持续等待授权。现在返回当前版本的封装密钥，并覆盖回归测试。
10. 本地消息附件 ID 是文件描述 ID，共享上传使用产物 ID；原先按错误字段关联，已上传文件不会出现在消息卡片。快照与增量都改按产物 ID 关联，增加真实文件落盘、共享上传、回读测试。
11. 退出账户后 Mac 项目密钥仍留在凭证库。现在统一登出和鉴权失效路径按账户清理；iPhone 退出项目或远端移除后也清理对应密钥、快照和文件缓存。
12. 共享附件采用项目、密钥版本、Chat 和请求 ID 范围的私有 R2 密文对象；服务端限制大小、数量、配额和发布状态，主机重新验证成员输入的明文大小及哈希。旧历史附件缺文件时同步明确失败，不静默发布不完整快照。
13. iPhone 增加独立项目级密文回放、账户隔离缓存、多人署名、文本发送/停止和附件 Quick Look；共享 Chat 打开期间定时刷新。共享协议版本不兼容时 API 返回升级错误；云端阅读和成员执行可分别关闭。

## 已具备的验证

- Account API：项目所有权与成员隔离、邀请、设备授权、来源发布、baseline 权限、命令 actor/目标主机/幂等/租约与撤权测试。
- Relay：项目隔离、加密事件、分页快照提交、按来源回收和当前 epoch 回放测试。
- Mac：共享字段白名单往返、原生 Session ID/工作目录/工具元数据不出共享视图；可信命令作者、持久队列、schema 迁移和多人署名测试。
- 共享附件单元测试覆盖跨项目拒绝、重复上传、未发布对象权限、撤权和密钥轮换；Swift XCTest 覆盖 Node 生成的 P-256/HKDF/AES 跨语言向量。
- `npm run typecheck`、`npm test`（481 通过、12 跳过）、`npm run build`、Account API 类型检查及测试（42 通过）、Relay 类型检查及测试（49 通过）、`npm run ios:typecheck`、iPhone 17 Pro Simulator XCTest（68 通过）及 `git diff --check` 均已通过。Web 预览只验证布局，不能证明真实账户或 Agent 执行链。
- iPhone 聊天布局测试原先在连续动画切换窗口时偶发读到空布局，并可能让 Simulator 占用过高。现在每种窗口尺寸单独构建静态界面，等待实际行出现后再检查留白；单项和完整 XCTest 已通过。

## 尚未关闭的发布阻断项

1. **[P0] 没有真实双账户、双 Mac、iPhone 联调。** 当前 Account API/Relay 使用本地模拟与单元测试；真实服务绑定、密钥轮换后的多机恢复、运行中撤权、离线主机与原生 Agent 续接必须在独立开发账户和开发云环境验证。
2. **[P1] 完整历史依赖发布主机在线重新生成当前 epoch baseline。** 轮换后旧 epoch 不再对成员回放；若有来源主机离线，界面显示部分历史待同步。需要用真实多机验证源主机恢复与长期离线策略。
3. **[P1] 灰度回滚及旧客户端混合版本未验收。** API 已用协议头拒绝旧版共享请求并区分阅读/执行开关，但还缺部署顺序、迁移演练和旧客户端收到升级提示的真实验证。
4. **[P2] iPhone 共享 Chat 暂不支持发送新附件。** 已支持查看和校验下载 Mac 成员发布的文件；手机新附件上传与失败恢复需单独设计并验收。该项不影响本轮 P6 文本协作目标。
